# Phase 3: Polished GUI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the dev harness into a real app: one window that swaps between a Home view (Play / Switch account), the WebView Login view (auto-closes on capture), and a Character-picker view — removing all CLI args. Inline status/errors; reuse the tested Core and the working two-leg login flow.

**Architecture:** Keep the `OsrsLauncher.Harness` project (renaming to `OsrsLauncher.App` is optional future cleanup; the packaged `.app` name is set in Phase 4). `MainWindow` hosts a swappable `ContentControl`; three `UserControl` views are swapped via simple code-behind navigation. Non-UI decision logic (`HomeViewModel`, character filtering) lives in `OsrsLauncher.Core` and is unit-tested. The existing two-leg WebView login logic is extracted into a reusable `JagexLoginFlow` that raises a completion event consumed by the Login view.

**Tech Stack:** C# / .NET 8, Avalonia 12 (`NativeWebView`), xUnit, existing `OsrsLauncher.Core`.

**Branch:** `phase-3-gui`. **Design (approved):** Home is default; with a saved session it shows the character + **Play** + **Switch account**; without one it shows **Log in**. Switch/Log in → WebView login (auto-closes on capture) → Character picker → pick → persist (Keychain) → back to Home. No auto-launch (Home + Play). Custom RuneLite path setting is deferred.

```csharp
// SPDX-License-Identifier: GPL-3.0-or-later
using OsrsLauncher.Core.Launch;
using OsrsLauncher.Core.Persistence;
using OsrsLauncher.Core.Session;

namespace OsrsLauncher.Core.App;

public sealed class HomeViewModel
{
    private readonly ICredentialStore _store;
    private readonly RuneLiteLauncher _launcher;

    public HomeViewModel(ICredentialStore store, RuneLiteLauncher launcher)
    {
        _store = store;
        _launcher = launcher;
    }

    public bool IsLoggedIn => _store.Load() is not null;
    public string? CharacterName => _store.Load()?.DisplayName;

    public void Play()
    {
        var s = _store.Load() ?? throw new InvalidOperationException("No stored session.");
        _launcher.LaunchJagexSession(new GameSession(s.SessionId), new JagexCharacter(s.AccountId, s.DisplayName));
    }
}
```

```csharp
using OsrsLauncher.Core.Session;

namespace OsrsLauncher.Core.App;

public static class CharacterFilter
{
    public static IReadOnlyList<JagexCharacter> Selectable(IReadOnlyList<JagexCharacter> all)
        => all.Where(c => !string.IsNullOrWhiteSpace(c.DisplayName)).ToList();
}
```

```csharp
public void ShowHome()   => Root.Content = new HomeView(this, _store, _launcher);
public void ShowLogin()  { var v = new LoginView(_config); v.Succeeded += (s, accts) => ShowPicker(s, accts); v.Failed += msg => ShowHome(/*with error*/); Root.Content = v; }
public void ShowPicker(GameSession s, IReadOnlyList<JagexCharacter> accts) => Root.Content = new CharacterPickerView(CharacterFilter.Selectable(accts), chosen => { _store.Save(new StoredSession(s.SessionId, chosen.AccountId, chosen.DisplayName)); ShowHome(); });
```

- [ ] **Step 2: HomeView** — binds to a `HomeViewModel(_store, _launcher)`:
